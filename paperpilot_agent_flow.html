v1.1 状态机与事件流

PaperPilot 现在不是简单 8 步脚本，而是保存阶段状态的研究工作流。每个 run folder 都有状态、清单和可审计中间产物。

Intake -> Protocol -> Search -> Corpus -> Screening -> Verification -> Synthesis -> Review -> Report
  • state.json 记录每个阶段的完成情况。
  • events.jsonl 记录 start、progress、stage、done 等事件。
  • manifest.json 记录最终产物清单和模型信息。
  • PaperPilot inspect <task-id> 可查看质量门、证据账本和复核结果。

质量门与偏题控制

报告质量不再只依赖排序分数，核心语料先经过纳入/排除标准和相关性筛选，然后生成综述级正文。

  • gRNAde 这类预印本/发表版通过标题相似度合并。
  • AutoDock Vina、RNA-SeQC、ProLIF、RTM-align 等偏题工具进入 exclude。
  • quality_gate.json 输出 pass、retry 或 needs_user_attention。

统一引用编号

报告生成阶段会以最终 report.papers 排序为唯一编号来源，把结构化论文位置都渲染成 [1]、[2] 这类引用。

report.papers -> citation_map -> paper_summaries / method_taxonomy / tables / references
  • 逐篇总结、方法流派代表论文、核心论文表、证据矩阵、代码表和 PDF 表都带编号。
  • 中英文 Markdown、HTML、PDF 共享同一个 report.canonical.json，编号和排序一致。
  • 参考文献区按 [n] 列出论文，若找到仓库则附带 Repository 链接。

Evidence Ledger + Review Agents

报告不只输出正文，还会为关键综述 claim 建立证据账本，并由轻量复核 Agent 检查来源、相关性、引用一致性和过度断言风险。

canonical report -> evidence_ledger.json -> review_agent_findings.json -> final report
  • evidence_ledger.json 把 claim 绑定到 [1]、[2] 等论文引用。
  • SourceVerifierAgent 检查 DOI、URL、PDF、代码状态。
  • CitationComplianceAgent 检查引用编号是否来自同一个 canonical paper list。
  • DevilsAdvocateAgent 标记小语料、质量门未过、证据缺口等过度解读风险。

Prompt / Tool / Capability Registry

Prompt 不再只是散落在 Python 函数里的字符串，而是带角色、版本和必需 JSON 字段的注册表。工具和能力也会写入运行目录，方便后续插件化。

prompt_manifest.json + registries.json + events.jsonl
  • Prompt Registry 管理 QueryUnderstanding、Planner、Protocol、Screening、Synthesis、Reflection、Abstract。
  • ToolRegistry 记录 arXiv、Semantic Scholar、OpenAlex、Crossref、OpenReview、GitHub、PDF、fulltext、report renderer。
  • CapabilityRegistry 预留 literature_review、systematic_review、code_reproducibility_review 和 topic_monitoring。

用户语料入口

除了在线检索，用户可以把已有 PDF、BibTeX、RIS、Markdown 或文本目录交给 PaperPilot，系统会把它们并入候选语料并记录导入日志。

--user-corpus ./papers --user-corpus references.bib
  • 本地 PDF 会以文件名作为最小标题进入语料，后续仍参与筛选和去重。
  • BibTeX / RIS 会尽量解析标题、作者、年份、DOI 和 URL。
  • 无法解析的文件写入 user_corpus_log.json，不会静默丢弃。

新增 CLI 能力

命令 / 参数 用途 默认行为
--mode quick|apa|systematic 控制报告形态 apa
--interaction auto|gated 控制是否在关键歧义处停下确认 auto
--quality fast|balanced|strict 控制质量门严格度 balanced
--include-adjacent 把相关但非核心论文纳入矩阵/附录 关闭
--user-corpus <path> 导入本地 PDF、BibTeX、RIS、Markdown 或文本语料 可重复传入
PaperPilot inspect <run> 查看状态、事件流、质量门、证据账本和复核 Agent 结果 只读
PaperPilot resume <run> 读取 task.json 并重新运行任务 复用原目录
